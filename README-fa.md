# PlayZone — راهنمای نصب (فقط با گوشی اندروید)

## مرحله ۱: ساخت ربات با BotFather
1. در تلگرام به **@BotFather** پیام بده و `/newbot` را بفرست.
2. یک نام (مثلاً PlayZone) و یک یوزرنیم که به `bot` ختم شود بده.
3. توکنی که دریافت می‌کنی (شکلی مثل `123456:ABC...`) را یادداشت کن. **این توکن را هیچ‌جا عمومی نکن.**

## مرحله ۲: آپلود کد در GitHub با گوشی
1. در مرورگر گوشی به github.com برو و یک Repository جدید به نام `playzone` بساز.
2. از گزینه **Upload files** فایل‌های پوشه پروژه (یا فایل ZIP را از حالت فشرده خارج کرده و فایل‌ها را) آپلود کن. ساختار پوشه‌ها باید حفظ شود.

## مرحله ۳: دیپلوی روی Render (هاست رایگان)
1. در **render.com** با حساب GitHub وارد شو.
2. گزینه **New → Blueprint** را بزن و repository پروژه را انتخاب کن. فایل `render.yaml` تنظیمات را خودکار می‌خواند.
3. قبل از Deploy، در بخش Environment این مقادیر را وارد کن:
   - `BOT_TOKEN` = توکن ربات از BotFather
   - `APP_URL` = فعلاً خالی بگذار (بعد از مرحله ۴ پر می‌شود)
   - `WEBHOOK_SECRET` به‌صورت خودکار ساخته می‌شود؛ آن را در بخش Environment کپی کن.
4. روی **Deploy** بزن. بعد از اتمام، آدرسی مثل `https://playzone-xxxx.onrender.com` می‌گیری.

## مرحله ۴: اتصال ربات و Mini App
1. مقدار `APP_URL` را با آدرس بالا پر کن و سرویس را یک بار Redeploy کن.
2. در مرورگر این آدرس را باز کن (با جای‌گذاری توکن و secret خودت):
```
https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=<APP_URL>/webhook/<WEBHOOK_SECRET>
```
   اگر پاسخ `"ok":true` دیدی، ربات متصل است.
3. ربات را در تلگرام باز کن و `/start` بفرست. دکمه **Play Game** باید ظاهر شود.

## بررسی سلامت
- آدرس `<APP_URL>/healthz` باید `ok` نشان دهد.
- در تلگرام `/help`، `/profile` و `/top` را امتحان کن.

## نکات مهم
- **ذخیره‌سازی:** نسخه رایگان Render فایل‌ها را بعد از ری‌استارت پاک می‌کند. برای نگهداری دائمی داده‌ها باید به PostgreSQL مهاجرت کنی (در نسخه بعد).
- **خواب سرویس:** در پلن رایگان، سرویس بعد از حدود ۱۵ دقیقه بی‌فعالیتی می‌خوابد و اولین درخواست کندتر است.
- **امنیت:** امتیازها فقط بعد از اعتبارسنجی initData تلگرام پذیرفته می‌شوند، هر نشست بازی یک‌بار مصرف است و امتیاز بیش از حد ممکن رد می‌شود. با این حال بازی در مرورگر اجرا می‌شود، پس امتیازهای تقلبی با حدس زدن مقدار ممکن است؛ تأیید کامل نیاز به منطق بازی در سرور دارد.
- **تست:** فایل `tests/test_app.py` را می‌توانی با `python tests/test_app.py` اجرا کنی.

## توسعه فقط با گوشی
- ویرایش کد در GitHub با مرورگر گوشی (فشردن کلید `.` روی صفحه repository محیط ویرایش را باز می‌کند).
- هر تغییر که commit شود، Render به‌صورت خودکار دیپلوی می‌کند.

## بخش‌های باقی‌مانده (نسخه بعد)
بازی‌های Dart، Memory و Puzzle، مسابقات روزانه/هفتگی، پنل مدیریت با رمز عبور، پیام همگانی و مهاجرت به PostgreSQL.
